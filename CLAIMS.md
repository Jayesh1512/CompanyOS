# Claim-to-evidence index

Generated by `node scripts/evidence/build.mjs`. This curated index links implemented capabilities to their retained evidence and verification scope.

Run `node scripts/evidence/verify.mjs` for offline integrity, scope consistency, heuristic secret checks, production-root quote signature replay and sanitized actual-AI record consistency. AI record checks cover sanitized original-call records; original SDK cryptographic verification is described in the linked evidence scope. Run `node scripts/evidence/run-local.mjs` separately for isolated native-JBrain and controlled pipeline tests. See [evidence guide](evidence/README.md).

Trust scopes: **LIVE_PUBLIC** = original public provider capture; **LIVE_PAID** = sanitized records of the approved actual owner-funded calls; **LIVE_LOCAL** = actual local execution; **CONTROLLED** = injected external facts. Each claim retains the provenance and verification scope of its supporting records.
